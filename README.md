# Aswin V A — Portfolio

A responsive, static portfolio built with plain HTML, CSS, and JavaScript. It can be hosted on Netlify without a backend or build step.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy to Netlify
1. Ensure `index.html`, `style.css`, `script.js`, and the `assets` folder are in the same project root.
2. Sign in to Netlify and choose **Add new site → Deploy manually** (the wording may vary).
3. Drag the extracted `aswin-portfolio` folder into the manual deploy area, or upload the folder contents as a deploy.
4. Open the generated site URL and test the résumé link and contact links.

No build command or publish directory is needed for this static site.

## Before publishing
- Check the résumé PDF in `assets/resume.pdf`.
- Verify the phone number and email are the contact details you want public.
- Add your GitHub and LinkedIn URLs if you want social links displayed. They were not added as clickable links because the resume content provided no verified profile URLs.
- The project visuals are CSS illustrations, not screenshots of actual client products.
